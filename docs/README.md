# Documentación del Proyecto

Esta carpeta centraliza el enunciado original, la base teórica de la asignatura y el análisis de marcos y casos de éxito de la industria para fundamentar el diseño del proyecto final de **Gamificación y Programación Funcional**.

## Índice

1. [Enunciado Original del Proyecto](./Enuncido-original-proyecto-gamificacion.md) — Casos de uso obligatorios y requisitos técnicos (`PRACTICO`).
2. [Fundamentos de Gamificación (Base del Curso)](./fundamentos-gamificacion.md) — Síntesis estructurada del contenido oficial de la materia: conceptos, mecánicas/dinámicas/objetos, neurociencia y motivación, modelo de Bartle, marco Octalysis, metodología de diseño, antipatrones y puente técnico con Redux.
3. [Análisis Profundo y Casos de Éxito](./casos-de-exito-y-patrones.md) — Marcos teóricos complementarios (SDT, MDA, Fogg, Hook Model), análisis de casos de éxito (Duolingo, Habitica, Todoist, Forest, GitHub, Asana, Strava, NRC, Starbucks, Trailhead, Foldit) y blueprint de mecánicas recomendadas (qué copiar y qué evitar) para la plataforma.
4. [Propuestas de diseño: cinco mundos](./propuestas/README.md) — Propuesta de aplicación, estrategia de gamificación, dirección visual, `DESIGN.md` y prompts para Stitch de las cinco direcciones (Panal, Órbita, Cumbre, Elay con Toco, Elay con Nando y Mechi), más la base común: casos de uso, motor de gamificación y diseño de Redux.
5. [Proyecto: Panal](./proyecto/README.md) — Documentación del proyecto que se va a construir, sobre la dirección elegida: PRD, historias de usuario, pantallas, stack y arquitectura, datos y API, y assets.
