PRACTICO 
Desarrollar una plataforma gamificada que ayude a organizar y cumplir 
actividades, de forma individual o en equipo. El objetivo es mostrar el 
cumplimiento de forma visual, con gráficos que permitan ver de un vistazo el 
avance de cada actividad y de cada proyecto. 
Casos de uso: 
• Registro e iniciar sesión. 
• Registrar actividades únicas y recurrentes. 
• Implementar sistema de gestión de proyectos (permitir la vinculación de 
usuarios) 
• Implementar un reporte a partir de graficas resaltando el progreso de 
cada acción 
Requisitos 
• Backend: Tecnologia libre. 
• Base de datos: Libre (obligatorio) 
• Frontend: La implementación de redux es obligatoria
